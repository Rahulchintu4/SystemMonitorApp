First, I used Visual Studio 2022 IDE to develop the application.

To run the project:

1. Clone the repository from GitHub using the below link:
https://github.com/Rahulchintu4/SystemMonitorApp.git

2. Open Visual Studio 2022.

3. Click on “Clone a Repository”.

4. Paste the GitHub repository URL and choose the local path.

5. Open the solution file after cloning.

6. Build the solution using:
   Build → Build Solution

7. Run the application by clicking Start or pressing F5.

After running the application, the console window displays
CPU usage(Dummy),real-time RAM usage, and Disk usage for every 5 seconds.
